# Data access and provenance

The R code expects `data/finalny_panel_przestrzenny_379_powiatow.rds` or `data/finalny_panel_przestrzenny_379_powiatow.csv.gz` in the project root. Neither file is included here. The dataset is a 379-county panel for 2010–2025. Model outcomes use age–sex-standardised all-cause mortality per 100,000 with 18 age groups × 2 sexes and a fixed reference distribution pooled over 2010–2019.

Core sources (see manuscript supplement for variable identifiers and constructions): Statistics Poland Local Data Bank; 2011 and 2021 population censuses; Copernicus Atmosphere Monitoring Service EAC4 (2010–2012) and European air-quality reanalysis (2013–2025); administrative county GIS boundaries and harmonization.

**Before any public deposit:** verify permissions for redissemination of raw and derived mortality values, census series, modelled air-quality datasets, and geographical files. Remove data that cannot legally be redistributed. Include source attribution, access dates, units, standardization reference weights or computation code, harmonization map for Wałbrzych, and complete column dictionary.

Once available, insert the real Zenodo record URL, DOI, version, dataset license, and access conditions here. Do not claim the full replication data are available before checking the deposit.
