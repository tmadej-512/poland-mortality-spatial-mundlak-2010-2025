# Social and environmental determinants of place-specific mortality inequality in Poland: a spatial Mundlak GAM

This repository contains the R code required to reproduce the analyses for the manuscript:

**Social and environmental determinants of place-specific mortality inequality in Poland: a spatial Mundlak generalised additive model for 379 counties, 2010–2019**

*Under review at Social Science & Medicine*

---

## Overview

This study integrates the Mundlak correlated random-effects decomposition with a spatially varying coefficient (SVC) generalised additive model (GAM) to analyse sub-regional mortality inequalities across 379 Polish counties (powiaty) over the pre-COVID period 2010–2019. A 2010–2023 panel including the COVID-19 period serves as a secondary sensitivity analysis.

The spatial Mundlak GAM simultaneously:

1. Separates each social and environmental determinant into a **between-county structural component** (persistent cross-sectional differences) and a **within-county temporal component** (year-to-year deviations from the county mean)
2. Estimates potentially **non-linear global exposure–response functions**
3. Maps **spatially varying local departures** from those functions across Polish counties

A debiased Mundlak ridge regression with dependent wild-bootstrap intervals serves as a transparent linear benchmark. Reliability of smooth effect surfaces is assessed using a novel spatiotemporally correlated perturbation procedure.

## Methods summary

**Outcome:** Age-sex standardised all-cause mortality rate (ASMR) per 100,000, 18 age groups × 2 sexes, 2010 national mean age-sex structure as standard population.

**Mundlak decomposition:** Each time-varying determinant *x*_it is decomposed into the county mean (between component) and the lagged annual deviation (within component, lag 1). Between-only determinants (education shares, distance to city) enter only the structural layer.

**Spatial Mundlak GAM:** Estimated by fREML using `mgcv::bam`. Specification includes a calendar-year smooth, a spatial baseline surface, global shrinkage smooths for each Mundlak component (k=3, m=1), and spatially varying coefficient (SVC) surfaces (k=50) estimated jointly with the global effects. Baseline spatial surface k=150; γ=1.4 for conservative shrinkage.

**Linear benchmark:** Mundlak ridge regression with 10-fold CV penalty selection, leave-one-out multiplicative debiasing, and dependent wild bootstrap intervals (B=1,000, AR(1) weights ρ=0.5).

**Perturbation analysis:** B=50 realisations of spatiotemporally correlated noise (temporal AR(1) from model residuals, spatial SAR parameter, σ=0.5). SNR = range of baseline curve ÷ mean SD of perturbed curves. Reliable: SNR > 2 and r_shape > 0.8.

## Reproducibility

Run from the repository root in order:

```r
source("R/RUN_ALL.R")
```

Or run individual steps:

```r
source("R/00_config.R")    # Load configuration
PERIOD <- "pre_covid"      # or "full"
source("R/00_config.R")    # Reload with period set

source("R/01_mundlak_ridge.R")   # ~5 min
source("R/02_stvc_gam.R")        # ~30–60 min
source("R/03_figures.R")         # ~10 min (reads RDS)
source("R/04_validation.R")      # ~20 min
source("R/05_perturbation.R")    # ~100 min (B=50)
```

`02_stvc_gam.R` is the computationally intensive step (GAM estimation). Results are saved as RDS files in `output/pre_covid/` and `output/full/`. All downstream scripts (`03_figures.R`, `04_validation.R`, `05_perturbation.R`) read these RDS files and do not re-estimate the model.
