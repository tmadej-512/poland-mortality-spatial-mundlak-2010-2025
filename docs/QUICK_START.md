# Quick start

1. Put the analytical panel in `data/finalny_panel_przestrzenny_379_powiatow.rds` or the CSV.GZ equivalent.
2. In RStudio open the repository root as the working directory.
3. The historical full run entry point is `source("R/RUN_ALL.R")` **only when intentionally rebuilding the analysis**. Do not run for GitHub/Zenodo upload.
4. The script paths may refer to specific project roots; review the configuration before attempting reproduction.
5. The exact figure-export package used for manuscript assembly is separate from this code release.
